Mesin database yang
bicara JSON, bukan SQL.

TeritipDB adalah mesin database yang menyimpan data ke penyimpan internalnya sendiri. Klien cukup mengirim JSON sederhana lewat HTTP — tanpa menulis SQL.

HTTP / JSON Windows / WSL Linux macOS VPS / Docker
Install lewat npm
npm create teritip-app@latest
Buka menu
teritip
Klien → (JSON/HTTP) → teritip-server → engine internal
